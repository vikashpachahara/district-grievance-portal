# 🏛️ District Public Grievance Portal

A professional web-based platform for citizens to lodge complaints directly to district authorities. This portal includes real-time evidence capture and high-priority emergency handling.

## 🚀 Key Features
* **📸 Real-time Evidence:** Capture photos directly from the webcam/phone camera or upload existing images.
* **🚨 One-Click SOS:** Immediate emergency report filing for high-priority police assistance.
* **📍 GPS Location:** Automatically attaches GPS coordinates to complaints for accurate field response.
* **🔍 Live Tracking:** Citizens can track the status of their grievance using a unique Tracking ID and a vertical progress timeline.
* **🛡️ Admin Dashboard:** A secure panel for officials to manage, update, and resolve complaints based on priority levels.

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Database:** SQLite3
* **Frontend:** HTML5, CSS3, Bootstrap 5 (Responsive Design)
* **Deployment:** Gunicorn & Render

## 📦 How to Run Locally
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Access at `http://127.0.0.1:5000`

## 🌐 Online Deployment
This project is configured for **Render**. Use the provided `Procfile` and `requirements.txt` for a seamless one-click deployment.
